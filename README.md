# Active Directory & Windows Server Home Lab

## Overview
Built a virtualized Active Directory domain environment on macOS using UTM to practice Windows system administration, account provisioning, and endpoint management.

## Infrastructure
- **Domain Controller:** Windows Server 2022 (Host: `DC01`, Domain: `lab.local`)
- **Client Workstation:** Windows 11 Enterprise (Joined to `lab.local`)
- **Hypervisor:** UTM for Mac

## Configurations & Tasks Completed
1. Installed and configured Active Directory Domain Services (AD DS) and DNS.
2. Created Organizational Units (OUs) for Departments (`IT`, `Sales`, `HR`).
3. Provisioned test user accounts and configured group membership.
4. Successfully joined client workstation to the domain and tested domain user logins.
